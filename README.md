# Akıllı Sulama Sistemi 🌱

Python programlama dili kullanılarak geliştirilen, Nesne Yönelimli Programlama (OOP) konularını uygulamalı olarak öğrenmeyi amaçlayan akıllı sulama sistemi projesidir.

## 📌 Proje Hakkında

Bu proje, sıcaklık ve nem sensörlerinden alınan verileri kullanarak otomatik sulama işlemini simüle eder.

Sistem, ortam koşullarını kontrol eder ve toprak nemi belirlenen seviyenin altına düştüğünde sulama sistemini otomatik olarak çalıştırır.

## ⚙️ Özellikler

- Sıcaklık sensörü simülasyonu
- Nem sensörü simülasyonu
- Otomatik sulama kontrolü
- Ayarlanabilir su akış hızı
- Cihazları açma ve kapatma işlemleri
- Giriş değerlerinin doğrulanması

## 🧠 Kullanılan OOP Konuları

Bu projede Nesne Yönelimli Programlamanın temel kavramları uygulanmıştır:

- **Class ve Object (Sınıf ve Nesne):** Cihazların ve sensörlerin sınıflar aracılığıyla oluşturulması.
- **Inheritance (Kalıtım):** Sensör ve sulama sınıflarının `Device` sınıfından türetilmesi.
- **Encapsulation (Kapsülleme):** Özel değişkenler kullanılarak verilerin korunması.
- **Polymorphism (Çok Biçimlilik):** Sınıfların kendilerine özgü `bilgi_goster()` metotlarını kullanması.
- **Composition (Bileşim):** Sensörlerin ve sulama sisteminin `SulamaKontrol` sınıfında bir araya getirilmesi.
- **Constructor (Yapıcı Metot):** Nesnelerin `__init__()` metodu ile başlatılması.
- **Super():** Üst sınıfın yapıcı metodunun yeniden kullanılması.

## 🛠️ Kullanılan Teknolojiler

- Python 3
- Nesne Yönelimli Programlama (OOP)
